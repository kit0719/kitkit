File Format Rules

Your text file must follow the KitKit engine parsing standard. The first line establishes the grid structure, and every subsequent line maps a specific cage.

# Line 1: [Grid Size] [Total Cages] N C # Following Lines: [Target] [Operator] [Size] [Row1] [Col1] [Row2] [Col2]... TARGET OP SIZE R C R C ...

3x3 Example Breakdown

A 3x3 grid with 5 cages would look like this inside the `.txt` file:

3 5 4 + 2 0 0 1 0 2 / 2 0 1 0 2 1 - 2 1 1 1 2 6 * 2 2 0 2 1 1 . 1 2 2
