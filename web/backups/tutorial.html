No Duplicates

In an NxN grid, you must fill the board using numbers 1 through N. Just like Sudoku, you cannot repeat a number in any single row or column.

The Cages & Math

The grid is divided into heavily outlined groups of cells called Cages. Each cage has a target number and a math operator (+, -, *, /) in the top-left corner. The numbers you place inside that cage must produce the target number using that operation.

Controls & Tools

KitKit is built for speed. Use your keyboard to navigate the grid instantly. If you get stuck, use your tools wisely.

  • Arrows

    Move the cyan selector around the grid.

  • 1 - 9

    Type a number to instantly place it in the selected cell.

  • Backspace

    Delete the number in the currently selected cell.

  • Hint

    Costs 1 Hint point. Reveals the correct number for a random empty cell.

  • Check

    Costs 1 Check point. Highlights any incorrect numbers currently on the board in red.
